# csb-aut-examen

# 🏅 Examen de Selección “Ingeniero de Calidad” – Consubanco

¡Bienvenido/a! Este repositorio contiene la prueba de selección para el puesto de QA Automatizador Senior. A continuación encontrarás todo lo necesario para completar los ejercicios de **Mobile**, **Web** y **API**.

---

## 📋 Contenido del Examen

1. **E2E Mobile**  
   - Validaciones de la APK _SwagLabs.apk_ usando Appium + Serenity BDD + Cucumber  
   - Escenarios de login, carrito y navegación de la app  

2. **E2E Web**  
   - Validaciones de la demo web _DemoBlaze_ con Serenity BDD + Cucumber  
   - Escenarios de sign-up, login, navegación de categorías, carrito y logout  

3. **API**  
   - Pruebas contra la API Petstore (Swagger) en Postman / Newman  
   - Creación, lectura, actualización y borrado de mascotas (CRUD)
